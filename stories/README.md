# Storybook stories

This directory contains [stories] and [documentation](#docs) rendered by
[Storybook]. The file layout should mimic the [src](../src/) directory: React
component stories and docs live in [react](./react/), etc.

## Docs

Component documentation is written in [MDX], a mashup of [Markdown] and JSX
(React). The [Storybook MDX docs] explain how to associate docs with component
stories and weave story embeds into prose.

[markdown]: https://en.wikipedia.org/wiki/Markdown
[mdx]: https://mdxjs.com/
[storybook]: https://storybook.js.org/
[Storybook MDX docs]: https://storybook.js.org/docs/writing-docs/mdx
[stories]: https://storybook.js.org/docs/writing-stories
