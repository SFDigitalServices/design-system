# Quick links

Quick links are built from the [QuickLink] and [QuickLinkSet] components.
`<QuickLink>` renders a hyperlink (`<a>`) with an `href`, a `heading`, and
optional `description`, while `<QuickLinkSet>` provides the responsive grid
layout for consistent vertical and horizontal alignment.
