# Container

The Container component establishes a consistent horizontal bounding box for
content. On viewports below the `xl` breakpoint, it applies a responsive
horizontal margin. At the `xl` viewport ({breakpoints.xl.value} or wider), the
content snaps to a centered column with a width of {widths.xl.value}.

<Canvas of={ContainerStories.Default} />

<Callout variant='warning'>
  Avoid adding horizontal padding to Container elements and their children,
  since this will alter the bounding box and break vertical alignment with other
  contained content.
</Callout>
