# Grid

The Grid component establishes a [CSS grid] with 6 columns on small viewports
and 12 on medium (`md`) widths and above.

<Callout>
  To ensure horizontal alignment with other elements, it's crucial that you wrap
  Grid elements in a Container.
</Callout>

## Columns

Direct children of the Grid element participate in the layout. The number of
columns that each child spans is determined by its [`col-span-*`][col-span] classes:

- `col-span-{1-12}` sets a numeric column span
- `col-span-full` spans all available columns

You can also use the [`col-start-*` and `col-end-*`][col-start-end] utility
classes to define the start and end columns, or combine `col-start-*` with
`col-span-*` to apply column offsets.

## Responsiveness

The 6-column grid is too narrow for content on smaller screens, so **in most
cases** it's best to have grid elements span the full grid initially with
`col-span-full` then snap to specific column widths on larger viewports with
`md:col-span-*`. For instance, a two-column grid template might look like:

```tsx
<Grid>
  <div className="col-span-full md:col-span-6">
    Column 1
  </div>
  <div className="col-span-full md:col-span-6">
    Column 2
  </div>
</Grid>
```
